# راوتر ESP32 فائق السرعة وإدارة الباقة والسرعات (High-Throughput NAPT Router)

مشروع فيرموير احترافي ومتكامل مبني على شريحة **ESP32** مع نواة **ESP-IDF v6.x** وخطافات مخصصة لطبقة الشبكة **lwIP NAPT**، يقدم راوتر ومكرر إشارة واي فاي كامل مع جدار ناري، محدد سرعة، تحكم بحصة الباقة، دعم وضع الألعاب VIP، وتصميم واجهة مستخدم زجاجي حديث (Glassmorphic UI) باللغة العربية مع دعم كامل للتيليجرام والريستارت اليومي التلقائي.

---

## 🌟 الميزات والمواصفات الرئيسية

### 1. واجهة مستخدم زجاجية حديثة مع محوّل سمات ديناميكي (Glassmorphic Design)
- **تصميم زجاجي عصري (Frosted Glass)** بتقنية `backdrop-filter: blur(20px)` وتدرجات ضوئية مريحة للعين.
- **شريط تبديل السمات الديناميكي**:
  - 🌅 **الغروب الكوني (Cosmic Sunset)**: خلفية فلكية داكنة مع لمسات متوهجة بألوان الغروب الدافئة ووردي نيون.
  - ⚡ **الأخضر السيبراني (Cyber Matrix)**: خلفية ماتركس خضراء مع توهج نيون إميرالد مستقبلي.
  - حفظ وتذكر السمة المفضلة تلقائياً عبر `localStorage`.
- رسم بياني مباشر لحركة البيانات وسرعة التحميل والرفع (HTML5 Canvas Real-Time Bandwidth Graph).
- نمطان لعرض الأجهزة: **بطاقات زجاجية تفاعلية (Cards View)** أو **جدول تفصيلي (Table View)**، متوافق 100% مع الهواتف الذكية.

### 2. تنبيهات استهلاك الباقة التلقائية المتعددة عبر التيليجرام (Multi-Threshold Push Alerts)
- **تنبيهات الباقة الرئيسية وباقات الأجهزة الفردية**:
  - فحص مستمر لنسبة استهلاك الباقة الكلية للراوتر، وكذلك نسبة استهلاك كل جهاز له حصة محددة.
  - إرسال إشعار فوري واحترافي باللغة العربية عبر التيليجرام فور تجاوز كل حد من الحدود المحددة (مثال: `50%, 75%, 90%, 95%, 100%`).
  - عند وصول استهلاك أي جهاز إلى 100%، يتم إرسال تنبيه حظر تلقائي وإيقاف وصوله للإنترنت فوراً.
- **منع التكرار والإزعاج**: تتبع الحدود التي تم إطلاقها وتفعيلها مرة واحدة فقط لكل دورة فوترة، مع إعادة ضبطها تلقائياً عند تجديد الباقة أو تصفير العدادات.

### 3. بوت التيليجرام التفاعلي المباشر (Interactive Telegram Bot - Pull Commands)
- مهمة FreeRTOS خلفية تعمل على النواة 1 بنظام **Long Polling (`getUpdates`)** المشفر عبر HTTPS/mbedTLS.
- يدعم مجموعة متكاملة من الأوامر والاستعلامات التفاعلية:
  - `🔹 /quota` أو `استهلاك` أو `باقي`: استعلام فوري عن رصيد باقة الراوتر الكلية، مع كشف استهلاك باقات الأجهزة المحددة.
  - `🔹 /devices` أو `أجهزة`: عرض الأجهزة المتصلة حالياً، سرعاتها اللحظية، باقاتها، سقوف السرعة وحالة الحظر.
  - `🔹 /speed` أو `سرعة`: قياس السرعة اللحظية للشبكة (تحميل ورفع) وحالة القناة 40MHz.
  - `🔹 /block [IP]` أو `حظر [IP]`: حظر جهاز متصل ومنعه من الإنترنت فوراً عبر lwIP NAPT.
  - `🔹 /unblock [IP]` أو `فك_حظر [IP]`: فك حظر الجهاز وإعادة وصول الإنترنت له فوراً.
  - `🔹 /status` أو `حالة`: تقرير مفصل عن حالة الراوتر، الذاكرة الحرة (RAM)، وتردد المعالج.
  - `🔹 /ota` أو `تحديث`: عرض تفاصيل إصدار الفيرموير الحالي وقسم الإقلاع الثنائي OTA.
  - `🔹 /reboot` أو `ريستارت`: إعادة تشغيل الراوتر عن بُعد بعد حفظ العدادات بأمان.
  - `🔹 /help` أو `مساعدة`: عرض دليل الأوامر التفاعلية الكاملة.

### 4. إعادة التشغيل اليومي التلقائي (Scheduled Daily Auto-Reboot)
- مزامنة مستمرة للوقت عبر بروتوكول NTP العالمي (`pool.ntp.org`).
- ضبط موعد يومي لإعادة التشغيل (مثال: `03:00 AM`) مع دعم فروق التوقيت الزمني (Timezone).
- حفظ العدادات والبيانات في NVS وتفريغ الذاكرة المؤقتة تلقائياً قبل تشغيل أمر `esp_restart()`.
- مؤقت ريستارت تنازلي سريع للتجربة والصيانة الدورية.

### 5. سعة اتصال مطورة وتحسين استهلاك الذاكرة (Ultra-Low RAM Footprint)
- رفع حد أجهزة الـ SoftAP إلى **12 جهاز متصل في نفس الوقت** (`max_connection = 12`).
- جدول تتبع موسع L3 IP/MAC لـ **32 جهاز نشط تزامناً** (أجهزة الواي فاي المباشرة والأجهزة المتصلة عبر رواتر أو سويتشات فرعية عبر عناوين الماك الحتمية `02:00:C0:A8:04:XX`).
- عرض عدد المتصلين في واجهة الويب بصيغة: `X / 12 متصل`.
- **Zero-RAM Web UI Serving**: الواجهة مضغوطة مسبقاً بتقنية Gzip ومخزنة في ذاكرة الفلاش `.rodata` وتُبث مباشرة برأس `Content-Encoding: gzip` بدون حجز أي بايت من الذاكرة العشوائية!
- **Chunked JSON Streaming**: بث الـ JSON في نهايات `/api/devices` و `/api/scan` باستخدام بافر على الـ Stack بدون `malloc`.
- تحرير ذاكرة البلوتوث عند الإقلاع (`esp_bt_controller_mem_release`) لتوفير أكثر من 30KB إضافية للذاكرة الحرة (تحقيق هدف: **>180 KB Free Heap**, **>110 KB Min Free Heap**).
- حزم هياكل البيانات باستخدام `__attribute__((packed))`.

### 6. تسريع تدفق البيانات وأقصى سرعة مع زمن استجابة منخفض (Speed Boost & Low Latency)
- خطاف حزم بيانات فائق السرعة في الـ IRAM مع جدول بحث مباشر `ip_lookup[256]` بفهرسة بالبايت الأخير لعنوان الـ IP لمطابقة فورية **O(1)** في دورة معالجة واحدة (1-cycle matching) بدون حلقات تكرارية أو أقفال أو عمليات رياضية عائمة.
- ضبط تردد قنوات الواي فاي على **عرض 40MHz (HT40)** وقوة بث راديو **20 dBm** لتحقيق سرعات فيزيائية تصل إلى 150 Mbps.
- أولوية فائقة لحزم الألعاب والـ Ping والـ VIP Gaming Mode مع تحديث سريع لرأس ToS DSCP EF.
- فصل حقيقي بين النواتين: النواة 0 مخصصة بالكامل لمهام الواي فاي و lwIP، والنواة 1 مخصصة لخادم الويب وحساب السرعات والتليجرام.

### 7. تحديد كوتة وسرعات مخصصة لكل جهاز (Per-Device Quota & Speed Limiting)
- **تخصيص كوتة بيانات بالجيجابايت لكل جهاز منفرد**: إمكانية تحديد سعة محددة (مثل 5 GB أو 10 GB أو 0 لغير محدود) لكل جهاز مباشرة من جدول الأجهزة أو البطاقات الزجاجية.
- **تتبع الاستهلاك الفعلي في الوقت الحقيقي**: حساب نسبة الاستهلاك المئوية وشريط تقدم ملون لكل جهاز.
- **حظر تلقائي صارم عند تجاوز الكوتة (Auto-Block at 100%)**: يتم حظر النت عن الجهاز فور استهلاك حصته بنسبة 100% وإشعار المشرف في الواجهة، مع فك الحظر تلقائياً بمجرد رفع الكوتة أو تصفير العداد.
- **تحديد سقف سرعة التحميل والرفع (Token-Bucket Rate Limiter)**: تحديد أقصى سرعة تحميل (Mbps) وأقصى سرعة رفع (Mbps) لكل عميل على حدة، مع تطبيق فوري بزمن تأخير صفري عبر الـ IRAM.

### 8. الترقية الهوائية الآمنة والذكية (Secure Over-The-Air OTA Updates)
- **نظام إقلاع مزدوج عالي الموثوقية (Dual-Bank OTA Partitioning)**: تقسيم الفلاش إلى بنكين متساويين (`ota_0` و `ota_1` بحجم 1.7 MB لكل منهما).
- **حماية كاملة من الأعطال (Anti-Rollback Protection)**: التحقق من صحة الفيرموير عند الإقلاع الأول، والتراجع التلقائي للنسخة السابقة العاملة في حال فشل الإقلاع.
- **طرق متطورة للتحديث من واجهة الويب**:
  1. **التحقق السحابي الآلي (Auto Cloud Version Check)**: فحص ملف `version.json` في المستودع بضغطة زر وعرض التحديث الجديد مع سجل التغييرات وزر التثبيت التلقائي المباشر.
  2. **رفع ملف مباشر (.bin Upload)**: رفع ملف الفيرموير المترجم مباشرة من الهاتف أو الكمبيوتر عبر المتصفح مع شريط تقدم مباشر دون الحاجة لإنترنت خارجي.
  3. **ترقية سحابية عبر رابط إنترنت (Remote OTA URL)**: تنزيل الفيرموير وتثبيته مباشرة من سيرفر سحابي أو خادم محلي.

## ⚡ كيفية البناء والحرق على الـ ESP32

### البناء (Build):
افتح PowerShell في مجلد المشروع ونفّذ:
```powershell
.\build_firmware.ps1
```

### الحرق على الـ ESP32 (Flash):
قم بتوصيل بوردة الـ ESP32 بالكمبيوتر عبر كابل الـ USB ونفّذ:
```powershell
.\flash_firmware.ps1 -Port COM3
```
*(استبدل COM3 برقم المنفذ الخاص ببوردتك)*.
